# 진도군 통합돌봄 모니터링 시스템

진도군 통합돌봄 7개 서비스(목욕, 가사, 식사(도시락), 미용, 이동, 스마트돌봄, 방문의료)의
월간 계획 → 승인 → 현장 기록 → 실시간 모니터링 → 위험 대응을 한 곳에서 관리하는 시스템입니다.

> 모든 이름과 수치는 **가상의 예시 데이터**입니다. 실제 개인정보는 이 저장소에 올리지 마세요.

## 폴더 구성

| 폴더 | 내용 | 실행 방법 |
|---|---|---|
| `prototype/` | **전체 시제품** (HTML·CSS·JS만, 서버 불필요). 최신 기능이 모두 들어 있음 | `prototype/index.html`을 브라우저로 열기, 또는 GitHub Pages |
| `server-php/` | **운영용 서버 1차 버전** (PHP + SQLite/MySQL). 로그인·권한·계획 승인·접속기록 | PHP 8.0 이상 필요. 아래 "PHP 서버 실행" 참고 |
| `docs/` | 시연 대본 등 문서 | |

### 시제품에만 있는 기능 (PHP 서버에 아직 없음)

- 통합돌봄 퇴원환자 지원 신청 페이지(로그인 없이 신청, 접수번호 조회)와 [퇴원지원] 처리 탭
- 퇴원지원 신청 알림 띠와 처리 창
- 현장 앱 하단 월별 방문 달력

운영용으로 쓰려면 이 기능들을 `server-php/`에 옮기는 작업이 남아 있습니다.

## 시제품 실행

- **내 PC에서**: `prototype/index.html`을 더블클릭해 브라우저로 엽니다.
- **GitHub Pages로 공개**: 저장소 Settings → Pages → Branch `main`, 폴더 `/ (root)` → Save.
  잠시 뒤 `https://<계정>.github.io/<저장소>/`에서 열립니다(루트 `index.html`이 `prototype/`으로 이동시킴).
- 체험 계정 비밀번호는 모두 `jindo1234`이며, 로그인 화면의 체험 계정 버튼으로 바로 들어갈 수 있습니다.
- 입력한 내용은 **보는 사람의 브라우저에만 저장**됩니다(서버 없음). 오른쪽 위 [초기화]로 처음 상태로 되돌립니다.

## PHP 서버 실행

```bash
cd server-php
cp config.example.php config.php   # Windows: copy config.example.php config.php
php install.php
php -S localhost:8080
```

`http://localhost:8080/login.php`를 엽니다. 자세한 설치·운영 안내는 [server-php/README.md](server-php/README.md)를 보세요.

## GitHub에 올리기 전 확인

- `server-php/config.php`(DB 비밀번호, 설치 키)와 `server-php/data/`(DB 파일)는 `.gitignore`로 제외되어 있습니다.
- **공개(Public) 저장소로 올리면 누구나 코드를 볼 수 있습니다.** 체험 계정 비밀번호가 코드에 들어 있으므로, 실제 운영 서버에서는 `DEMO_MODE`를 끄고 계정 비밀번호를 모두 바꾸세요.
- 실제 어르신 정보, 실제 병원·담당자 이름, 연락처는 절대 커밋하지 마세요. 공개 전에 비공개(Private) 저장소로 시작하는 것을 권합니다.
- 시연영상(MP4, 약 48MB)은 저장소에 넣지 않았습니다. GitHub는 100MB까지 올릴 수 있지만, 영상은 Releases나 별도 공유를 권합니다.

## 주요 기능

| 역할 | 기능 |
|---|---|
| 총괄 담당자 | 연·월·일 대시보드, 집중관리 대상, 퇴원지원 처리, 계획 승인·반려, 변경 요청 처리, 계정 발급, 긴급·퇴원지원 알림 |
| 수행기관 관리자 | 자기 기관 현황, 월간 계획 작성(일괄 이동·이관·추가, 자동 점검)·제출, 수행자 계정 |
| 현장 수행자 | 오늘 방문 시작·종료·건강상태, 취소, 일정 변경 요청, 긴급, 월별 방문 달력 |
| 시스템 관리자 | 전체 계정, 접속기록 |
| 조회 전용 | 대시보드 보기 |
| 누구나 (로그인 없이) | 퇴원환자 지원 신청, 접수번호로 진행 상황 확인 |
